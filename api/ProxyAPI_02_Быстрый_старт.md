# ProxyAPI: быстрый старт

Источник (сверено 24.11.2026, редакция страницы от 02.09.2026):
- https://proxyapi.ru/docs/quickstart

Для первого запроса нужны три вещи: аккаунт, ключ API и деньги на балансе.

## 1. Регистрация

Аккаунт создаётся в личном кабинете ProxyAPI. На почту приходит письмо со ссылкой подтверждения, без него кабинет не откроется.

## 2. Ключ API

- Раздел кабинета **Ключи API**.
- Ключ - строка, начинается с `sk-`.
- Целиком ключ показывается **один раз**, сразу после создания. Потеряли - создайте новый.

## 3. Баланс

- Оплата по факту: стоимость запроса списывается после выполнения.
- Пополнение: раздел **Биллинг**, рублями с российской карты.
- При пустом балансе запросы не выполняются, приходит ошибка о недостатке средств (402).

## 4. Первый запрос

Python, официальная библиотека OpenAI (`pip install openai`). Отдельная библиотека для ProxyAPI не нужна.

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PROXYAPI_API_KEY"],
    base_url="https://api.proxyapi.ru/v1",
)

response = client.chat.completions.create(
    model="openai/gpt-5-mini",
    messages=[
        {"role": "user", "content": "Привет!"}
    ],
)

print(response.choices[0].message.content)
```

То же через curl:

```sh
curl "https://api.proxyapi.ru/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <КЛЮЧ>" \
  -d '{
    "model": "openai/gpt-5-mini",
    "messages": [{"role": "user", "content": "Привет!"}]
  }'
```

`openai/gpt-5-mini` - недорогая и быстрая модель, удобна для проверки. Вместо неё можно указать любую модель из каталога на сайте ProxyAPI.

## Частые проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| Ошибка 401 | В коде адрес поставщика (например `api.openai.com`) или ключ, полученный у поставщика | Указать `base_url="https://api.proxyapi.ru/v1"` и ключ ProxyAPI |
| Ошибка о недостатке средств (402) | На балансе не хватает денег | Пополнить баланс в разделе «Биллинг» |
| Не знаю, какие модели есть | | Каталог моделей с ценами на сайте ProxyAPI. Программно - запрос к эндпоинту моделей |
