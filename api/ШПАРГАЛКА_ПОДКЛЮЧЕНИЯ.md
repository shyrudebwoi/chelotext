# Шпаргалка подключения

Минимальный рабочий код для Python-приложения (Flask и др.). Подробности - в файлах GigaChat_* и ProxyAPI_*.

## Зависимости

```
pip install requests python-dotenv certifi openai
```

`openai` нужна только для ProxyAPI.

## .env

```
GIGACHAT_CRED=
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2
PROXYAPI_API_KEY=
```

Значения вписывает человек вручную. Правила - в `БЕЗОПАСНОЕ_ДОБАВЛЕНИЕ_API_КЛЮЧЕЙ.md`.

## GigaChat за 3 шага

| Шаг | Что | Куда |
|---|---|---|
| 1 | Сертификат Минцифры | `certs/russian_trusted_root_ca.crt` (скачать с https://www.gosuslugi.ru/crt) |
| 2 | Токен доступа (живёт 30 минут) | POST `https://ngw.devices.sberbank.ru:9443/api/v2/oauth` |
| 3 | Запрос к модели | POST `https://api.giga.chat/v1/chat/completions` |

Файл `gigachat_service.py`:

```python
import os
import time
import uuid
from pathlib import Path

import certifi
import requests
from dotenv import load_dotenv

load_dotenv()

OAUTH_URL = "https://ngw.devices.sberbank.ru:9443/api/v2/oauth"
CHAT_URL = "https://api.giga.chat/v1/chat/completions"
CA_BUNDLE = Path("certs/ca_bundle.pem")
RU_CA = Path("certs/russian_trusted_root_ca.crt")

_token = None
_token_expires_at = 0.0


def _ca_bundle() -> str:
    # Стандартные сертификаты + сертификат Минцифры, собираются один раз
    if not CA_BUNDLE.exists():
        CA_BUNDLE.write_text(
            Path(certifi.where()).read_text(encoding="utf-8") + "\n" + RU_CA.read_text(encoding="utf-8"),
            encoding="utf-8",
        )
    return str(CA_BUNDLE)


def _get_access_token() -> str:
    global _token, _token_expires_at
    if _token and time.time() < _token_expires_at - 60:
        return _token
    cred = os.getenv("GIGACHAT_CRED")
    if not cred:
        raise RuntimeError("Не задан GIGACHAT_CRED в .env")
    resp = requests.post(
        OAUTH_URL,
        headers={
            "Content-Type": "application/x-www-form-urlencoded",
            "Accept": "application/json",
            "RqUID": str(uuid.uuid4()),
            "Authorization": f"Basic {cred}",
        },
        data={"scope": os.getenv("GIGACHAT_SCOPE", "GIGACHAT_API_PERS")},
        verify=_ca_bundle(),
        timeout=30,
    )
    resp.raise_for_status()
    data = resp.json()
    _token = data["access_token"]
    _token_expires_at = data["expires_at"] / 1000  # приходит в миллисекундах
    return _token


def ask_gigachat(user_text: str, system_prompt: str = "Ты полезный ассистент.") -> tuple[str, dict]:
    resp = requests.post(
        CHAT_URL,
        headers={
            "Content-Type": "application/json",
            "Accept": "application/json",
            "Authorization": f"Bearer {_get_access_token()}",
            "User-Agent": "study-app",
        },
        json={
            "model": os.getenv("GIGACHAT_MODEL", "GigaChat-2"),
            "messages": [
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": user_text},
            ],
        },
        verify=_ca_bundle(),
        timeout=60,
    )
    resp.raise_for_status()
    data = resp.json()
    return data["choices"][0]["message"]["content"], data.get("usage", {})
```

## ProxyAPI

```python
import os

from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.environ["PROXYAPI_API_KEY"],
    base_url="https://api.proxyapi.ru/v1",
)


def ask_proxyapi(user_text: str, system_prompt: str = "Ты полезный ассистент.") -> tuple[str, dict]:
    response = client.chat.completions.create(
        model="openai/gpt-5-mini",
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_text},
        ],
    )
    return response.choices[0].message.content, response.usage.model_dump()
```

## Сравнение

| | GigaChat | ProxyAPI |
|---|---|---|
| Цена | Бесплатные токены для физлиц (freemium) | Платно, с баланса за каждый запрос |
| Авторизация | Ключ авторизации -> токен на 30 минут | Один ключ `sk-...` |
| Адрес | `https://api.giga.chat/v1` | `https://api.proxyapi.ru/v1` |
| Сертификат Минцифры | Нужен | Не нужен |
| Библиотека | `requests` или SDK `gigachat` | `openai` |
| Текст ответа | `choices[0].message.content` | `choices[0].message.content` |
| Расход токенов | `usage.total_tokens` | `usage.total_tokens` |

## Если не работает

| Симптом | Первое, что проверить |
|---|---|
| `CERTIFICATE_VERIFY_FAILED` | Сертификат Минцифры (GigaChat_01) |
| GigaChat 400 / 401 при получении токена | `RqUID`, `scope`, ключ без опечаток, `Basic <ключ>` |
| GigaChat 401 при запросе к модели | Токен истёк, нужен новый |
| GigaChat 403 | Заголовок `User-Agent` |
| GigaChat 402 | Закончились токены выбранной модели |
| GigaChat 429 | Запросы идут параллельно, а физлицам доступен 1 поток |
| ProxyAPI 401 | Адрес `https://api.proxyapi.ru/v1` и ключ ProxyAPI, а не OpenAI |
| ProxyAPI 402 | Баланс или бюджет ключа |
| Переменная не найдена | Файл `.env` сохранён? Приложение перезапущено? |
