# Документация API для учебного проекта

Короткие выжимки из официальной документации двух сервисов, через которые приложение обращается к нейросети:

- **GigaChat API** (Сбер) - основной вариант. Физлицам доступны бесплатные токены.
- **ProxyAPI** - платный посредник к моделям OpenAI, Anthropic, Google и других. Оплата рублями.

Файлы сверены с официальными страницами 24.11.2026. Сервисы обновляют API: если что-то не совпадает, верна ссылка-источник в начале каждого файла.

## Как использовать с ИИ-агентом

1. Подключаете один сервис - давайте агенту только его файлы, плюс `БЕЗОПАСНОЕ_ДОБАВЛЕНИЕ_API_КЛЮЧЕЙ.md` и `ШПАРГАЛКА_ПОДКЛЮЧЕНИЯ.md`. Если в контексте окажутся оба провайдера, агент может их перепутать.
2. В запросе прямо называйте провайдера. Пример:

```
Используй документацию из папки Документация_API по подключению GigaChat
(файлы GigaChat_*, БЕЗОПАСНОЕ_ДОБАВЛЕНИЕ_API_КЛЮЧЕЙ.md, ШПАРГАЛКА_ПОДКЛЮЧЕНИЯ.md).
Добавь всё необходимое для подключения нейросети к моему проекту.
Дай инструкцию, куда я должен вручную добавить API-ключ.
Не вставляй секрет в исходный код, не проси присылать его в чат и не выводи его в логах.
```

3. Ключи в эти файлы не вписываются. Значения ключей человек сам вносит в `.env`.
