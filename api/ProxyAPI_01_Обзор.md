# ProxyAPI: обзор

Источник (сверено 24.11.2026, редакция страницы от 02.09.2026):
- https://proxyapi.ru/docs/overview

## Что это

ProxyAPI - посредник для доступа к API моделей OpenAI, Anthropic, Google, DeepSeek и других поставщиков.

- Аккаунты у поставщиков (OpenAI, Anthropic и т.д.) не нужны. Ключ, оплата и статистика - в личном кабинете ProxyAPI.
- Оплата рублями с российской карты. VPN не нужен.
- Сервис **платный**: деньги списываются с баланса за каждый запрос.

## Как это работает

1. Приложение отправляет запрос на сервер ProxyAPI.
2. Запрос уходит конечному сервису через цепочку прокси-серверов в Европе.
3. Ответ возвращается в том же виде, в каком его отдал сервис. Обработку ответа в коде менять не нужно.

Ключ ProxyAPI работает **только** с адресом ProxyAPI. При прямом обращении к OpenAI или другому поставщику он не сработает.

## Совместимость

- Запросы и ответы устроены как в API OpenAI. Подходит официальная библиотека `openai` и любые инструменты, которые умеют работать с OpenAI: достаточно заменить базовый адрес и ключ.
- Также поддерживаются форматы Anthropic Messages, OpenAI Responses и Google Gemini.

| Параметр | Значение |
|---|---|
| Базовый адрес (формат OpenAI) | `https://api.proxyapi.ru/v1` |
| Авторизация | `Authorization: Bearer <ключ ProxyAPI>` |
| Формат ID модели | `поставщик/модель`, например `openai/gpt-5-mini` |
