## 1. Формулировка задачи (от пользователя)
Спроектировать веб-приложение «Челотекст». Оно **меняет подачу текста, но сохраняет смысл, факты, имена и цифры**. Требуется: интервью из 10 уточняющих вопросов (по одному), затем подробное ТЗ: цель, аудитория, сценарий, структура и экраны, функции, данные, состояния интерфейса, ограничения, требования к мобильной версии, критерии приёмки. Код на этом этапе не пишется.

## 2.1. Второй раунд: PDF и Tesseract OCR (23.11.2026)

Пользователь поставил правку: поддержать вход PDF с распознаванием через Tesseract. Уточняющие вопросы и ответы:

| # | Тема | Вопрос | Ответ пользователя | Принятое решение (в ТЗ) |
|---|------|--------|--------------------|--------------------------|
| P1 | Типы PDF | Какие PDF поддерживаем? | И те, и другие | Гибридный подход: текстовый слой — извлекаем напрямую; скан — Tesseract OCR; смешанные — постранично (TZ 4.3.1). |
| P2 | Качество/скорость | Согласны на асинхронность + предупреждение? | Да: предупреждение «текст распознан, возможны ошибки» и сразу в редактор | Скан-PDF всегда через очередь; по готовности — уведомление, предупреждение OCR и автооткрытие во встроенном редакторе (TZ 4.3.1, 5). |
| P3 | Структура | Сохранять или упрощать? | Максимально сохранить | Таблицы → Markdown-таблицы; колонки — в порядке чтения; колонтитулы/номера страниц вырезать; сноски → отдельный список с привязкой по номеру (TZ 4.1.1). |
| P4 | Языки и лимиты | Какие языки OCR? Лимиты? | rus + eng (могут быть в одном файле); лимит — 100 000 знаков или 50 страниц | Tesseract `rus+eng`, список языков конфигурируем; лимит PDF: 100 000 знаков ИЛИ 50 страниц (что раньше); лимит знаков общий с текстовым входом (TZ 4.3.1). |

Дополнительно зафиксировано: OCR-результат помечается в истории как «получен из OCR»; Tesseract — самохостимый (вписывается в бюджет ≈ 0); задача отменяема на любой стадии, включая OCR.

## 2.2. Третий раунд: подключение LLM GigaChat (25.11.2026)

Пользователь попросил изучить папку `api/` и подготовить `.env`, куда сам впишет ключи.
Выбран **GigaChat API** (Сбер) как основной провайдер: бесплатные токены физлицам,
русский язык, RFC-совместимый формат `chat/completions`.

| Тема | Решение |
|---|---|
| Авторизация | Поддерживаются два варианта: готовый `GIGACHAT_CRED` (Authorization Key) **или** `GIGACHAT_CLIENT_ID` + `GIGACHAT_CLIENT_SECRET` (сервер сам собирает Basic как base64(`id:secret`)). |
| Срок токена | Access token живёт 30 минут, кэшируется и обновляется за 60 сек до истечения. Новый `RqUID` (uuid4) на каждый запрос токена. |
| Адреса | OAuth `https://ngw.devices.sberbank.ru:9443/api/v2/oauth`, API `https://api.giga.chat/v1` (старый `gigachat.devices.sberbank.ru` не используется). |
| Сертификат | Нужен корневой сертификат НУЦ Минцифры; добавляется в доверенные через `npm run certs`, проверка TLS **не отключается**. |
| Параллелизм | Физлицам доступен 1 поток — запросы к GigaChat сериализуются; при 429/502/504 — backoff. |
| Безопасность | Секреты только в `.env` (в `.gitignore`), в логи/ответы не попадают; браузер ключ не получает. |
| Отказоустойчивость | Если ключ не задан или API недоступен, задача падает на движок правил без ошибки пользователю; в `llm.fallbackReason` пишется причина. |
| ProxyAPI | Оставлен как запасной OpenAI-совместимый вариант (`LLM_PROVIDER=openai`, `LLM_BASE_URL=https://api.proxyapi.ru`, ключ `sk-...`), платный. |

## 3. Ключевые принятые решения (сводка)
- **Массовая аудитория**, русский язык, текст **не сокращается** — меняется подача.
- **MVP = копипаст**; ссылка и файлы — ближайшая очередь.
- **3 режима** обработки (форматирование / упрощение / структурирование) + **ползунок глубины**.
- **Вход** до 100 000 знаков. **Выход:** экран, копирование, скачивание (TXT/PDF/MD обязательно; DOCX/HTML по возможности), параллельный вид с diff, редактор результата.
- **Аккаунты + история + gate согласия ПДн.**
- **Предпроверка** контента (без незаконного/чужого авторского, кроме научных статей).
- **Бюджет ≈ 0:** приоритет бесплатных тарифов LLM / открытых моделей / гибрид «правила+модель»; заменяемый слой провайдера LLM. **OCR — самохостимый Tesseract (бесплатно).**
- **Асинхронная очередь** для длинных текстов; прогресс и отмена.
- **Адаптивная мобильная вёрстка.** Офлайн — не в MVP.
- **Дизайн** — по будущему `design.md`.
