## 1. Проект и правила

**Челотекст** — PWA, которая меняет подачу текста, сохраняя смысл, факты, имена, числа, даты и цитаты.
Рабочая папка: `C:\proj\chelotext`. Исходные требования: `docs/TZ.md`, `docs/design.md`, `docs/PROMPT.md`.

Жёсткие ограничения (не нарушать):
- Меняется только подача; сокращать содержание нельзя. Смысл/факты/имена/числа/даты/цитаты — 1:1.
- 3 независимых режима R1/R2/R3 + ползунок глубины 1–5.
- Лимит 100 000 знаков (клиент + сервер); PDF — 100k знаков ИЛИ 50 страниц.
- Gate согласия ПДн: без согласия 403; отзыв согласия → удаление данных.
- Предпроверка: блокировать незаконное и чужой авторский текст целиком; научные статьи пропускать.
- Скан-PDF всегда асинхронно, метка «из OCR», отмена на любой стадии.
- Экспорт: TXT/PDF/MD/DOCX/HTML. Бюджет ≈ 0.
- В `.env` включён провайдер `gigachat`, но ключи пока пустые → работает только движок правил (fallback без ошибки).
  Пользователь сам впишет `GIGACHAT_CRED` **или** `GIGACHAT_CLIENT_ID` + `GIGACHAT_CLIENT_SECRET`, затем перезапустит сервер.

### Критичные баги, исправленные ранее (не сломать заново)
- `\b` не работает с кириллицей → `server/lib/regex.js` `cyrify()` (Unicode lookaround). Применён в
  `engine.js`, `precheck.js`, в `isScientific()` (SCIENTIFIC_MARKERS) и в `readability()` (bureau-паттерн).
- `dedupeRepeats` удалял разнесённые повторы через глобальный `Set` → потеря 97% текста.
  Переписан: удаляются только **соседние** дубликаты.
- `buildLineDiff` не обрабатывал тип `changed` → добавлена ветка.
- Артефакты правил («, .», «Которая это», падежи): фразовые замены раньше однословных,
  «в целях» → «для», «представляет собой» → «— это», убраны опасные однословные замены;
  в `engine.js` — `cleanupSpacing`, `capitalizeStart`, `canStartSentence` + `DEPENDENT_START`,
  `SPLIT_CONNECTORS` без «который/если/чтобы».
- CSS: `[hidden]{display:none!important}`; overflow-x истории → `minmax(0,1fr)`, `min-width:0`,
  `align-items:stretch` в mobile-блоке.
- `render.js`: версионирование статики `asset()/assetVersion()` (sha1 по size+mtime+содержимому).
- 404/500 были пустыми → `notFound()`/`serverError()` из `server/pages/index.js`.

### Сессия «PWA + eval» (закрыта)

**PWA — закрыто.**
- Найден баг: регистрация SW была обёрнута в `window.addEventListener('load', …)` в `public/js/app.js`.
  Модульный скрипт (`type="module"`) мог выполниться после `load`, и регистрация терялась —
  `/sw.js` вообще не запрашивался. Исправлено: `navigator.serviceWorker.register('/sw.js')` вызывается сразу.
- Проверено в браузере: консоль `[pwa] sw registered http://127.0.0.1:3311/`;
  при **остановленном** сервере `/app` отдаётся из кэша, а `/history?nocache=offline-test` →
  офлайн-страница «Нет сети». Все 11 precache-ресурсов отвечают 200. Manifest валиден
  (shortcuts, maskable-иконка, `start_url: /app`).
- Отладочный `console.log` после проверки убран.

**Eval — закрыто.**
- `eval/texts/` — 18 русских текстов разных жанров: канцелярит, новость, популяризация науки,
  инструкция, договор, медицина, финансы, блог, деловое письмо, пресс-релиз, научный абстракт
  (с DOI и статистикой), интервью, карточка товара, учебник, вакансия, госуслуги, техдок, эссе.
- `eval/run.js` — прогон через `runPipeline` (только правила), метрики:
  сохранность сущностей (integrity), объём (порог 0.8–1.6), Flesch до/после, средняя длина
  предложения, канцелярит на 1000 слов. Отчёт → `eval/report.md`. Exit code 1 при провале.
- Найдено и исправлено 2 бага:
  1. `cleanupSpacing` (`server/core/rules/engine.js`) вставлял пробел в десятичные дроби:
     «2,2» → «2, 2», «0,05» → «0, 05» → integrity фиксировал потерю чисел.
     Фикс: после `,` пробел не ставится, если слева и справа цифры.
  2. `checkIntegrity` (`server/core/integrity.js`) сравнивал даты с учётом регистра, а
     `capitalizeStart` поднимает «г.» → «Г.» в начале абзаца («г. Москва» → «Г. Москва»),
     из-за чего «2026 г.» считалось потерянным. Фикс: даты нормализуются в нижний регистр.
- **Результат: 18/18 OK, avgRatio 100%, avgScore 100%, exit 0. Тесты на тот момент 118/118 (сейчас 140).**

## 7. Грабли окружения

- **Windows-консоль ломает кириллицу** (cp866). Любой вывод node-скриптов с русским текстом писать
  в `tmp/*.txt` и читать через `read_file`, иначе получите «╨з╨╡╨╗╨╛╤В╨╡╨║╤Б╤В».
- `grep` в bash-обёртке тоже может искажать вывод — для чтения кода использовать `read_file`.
- e2e-тесты используют temp-директорию и env — рабочую БД не трогают.
- Сервер на 3311 мог остаться запущенным; проверять `curl.exe -s -o $null -w "%{http_code}" http://127.0.0.1:3311/` (в PowerShell), не `-o NUL` — в Windows это создаёт файл с таким именем.
- Порт занят (`EADDRINUSE`) — значит сервер уже работает, второй экземпляр не нужен.
- `browser evaluate` в Koda Desktop выключен настройками; проверять через `console`/`requests`/`snapshot`.

## 9. Известные ограничения (для документации)

- Живой вызов GigaChat не проверялся (нет ключей): пока качество упрощения ограничено движком правил;
  R2 работает как «правила + заглушка». После ввода ключей поведение изменится — нужна проверка.
- Офлайн-обработка не поддерживается (ТЗ 5): офлайн доступна только оболочка и заглушка.
- OCR медленный на слабых машинах (рендер страниц через canvas + Tesseract).
- Сокращения вида «г.» в начале абзаца капитализируются («Г. Москва») — нормализовано в integrity,
  но визуально это правка регистра, которую стоит упомянуть в ограничениях.
